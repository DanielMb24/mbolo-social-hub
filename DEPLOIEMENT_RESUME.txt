🚀 DEPLOIEMENT EN 3 ETAPES :

1️⃣  PREPARER (2 min)
   
   Windows :
   > deploy-render.bat
   
   Linux/Mac :
   $ chmod +x deploy-render.sh
   $ ./deploy-render.sh

2️⃣  DEPLOYER (5 min)
   
   • Allez sur https://dashboard.render.com
   • Cliquez "New" → "Blueprint"
   • Sélectionnez votre repo GitHub
   • Configurez les variables d'environnement
   • Cliquez "Apply"

3️⃣  VERIFIER (1 min)
   
   Windows :
   > verify-deployment.bat
   
   Linux/Mac :
   $ chmod +x verify-deployment.sh
   $ ./verify-deployment.sh

🔑 VARIABLES D'ENVIRONNEMENT REQUISES :

Vous devrez configurer ces variables dans Render :

• MAIL_USERNAME              (Gmail)
• MAIL_PASSWORD              (Gmail App Password)
• GOOGLE_CLIENT_ID           (Google OAuth)
• GOOGLE_CLIENT_SECRET       (Google OAuth)
• MINIO_ACCESS_KEY           (MinIO/S3)
• MINIO_SECRET_KEY           (MinIO/S3)
• JWT_SECRET                 (Secret fort)

Voir .env.production.example pour la liste complète

🎯 SERVICES DEPLOYES :

Après déploiement, vous aurez 8 services :

1. mbolo-frontend              (React + Nginx)
2. mbolo-gateway               (API Gateway)
3. mbolo-auth                  (Authentification)
4. mbolo-user                  (Gestion utilisateurs)
5. mbolo-chat                  (Messagerie)
6. mbolo-post                  (Publications)
7. mbolo-video                 (Vidéos)
8. mbolo-moderation            (Modération)

+ 6 bases MongoDB + 1 Redis
