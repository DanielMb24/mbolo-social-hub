4. CONFIGURATION REQUISE
========================================

EMAIL (Auth Service):
1. Creer backend/auth-service/.env
2. Ajouter MAIL_USERNAME et MAIL_PASSWORD
3. Pour Gmail: utiliser mot de passe application

DEPENDANCES FRONTEND:
npm install sockjs-client @stomp/stompjs
npm install --save-dev @types/sockjs-client

Ou executer: install-chat-deps.bat

5. DEMARRAGE RAPIDE

8. ENDPOINTS DISPONIBLES
========================================

AUTH SERVICE (port 8081):
POST /api/auth/forgot-password
POST /api/auth/reset-password
POST /api/auth/register
POST /api/auth/login
POST /api/auth/refresh

CHAT SERVICE (port 8083):
GET  /api/chat/conversations
POST /api/chat/conversations
GET  /api/chat/conversations/private/{userId}
GET  /api/chat/messages/{conversationId}
POST /api/chat/messages
PUT  /api/chat/messages/{messageId}/seen
PUT  /api/chat/conversations/{conversationId}/seen
DELETE /api/chat/messages/{messageId}

WEBSOCKET:
ws://localhost:8083/ws-chat
