## 🎯 Scénarios d'Usage

### "Je découvre le projet"
1. Lisez [QUICK_START.md](./QUICK_START.md)
2. Parcourez [README.md](./README.md)
3. Consultez [PROJECT_STATUS.md](./PROJECT_STATUS.md)

### "Je veux installer et tester"
1. Suivez [QUICK_START.md](./QUICK_START.md)
2. Exécutez `./install.sh` ou `install.bat`
3. Lancez `npm run dev`
4. Consultez [COMMANDS_CHEATSHEET.md](./COMMANDS_CHEATSHEET.md) si besoin

### "Je veux contribuer"
1. Lisez [CONTRIBUTING.md](./CONTRIBUTING.md)
2. Consultez [PROJECT_STATUS.md](./PROJECT_STATUS.md)
3. Référez-vous à [COMMANDS_CHEATSHEET.md](./COMMANDS_CHEATSHEET.md)

### "Je veux déployer en production"
1. Lisez [DEPLOYMENT.md](./DEPLOYMENT.md)
2. Consultez [backend/DEPLOYMENT.md](./backend/DEPLOYMENT.md)
3. Configurez les variables d'environnement
4. Suivez les étapes de déploiement

### "J'ai un problème"
1. Consultez [QUICK_START.md](./QUICK_START.md) - Section "Problèmes Courants"
2. Vérifiez [COMMANDS_CHEATSHEET.md](./COMMANDS_CHEATSHEET.md) - Section "Dépannage"
3. Lisez [DEPLOYMENT.md](./DEPLOYMENT.md) - Section "Troubleshooting"
4. Exécutez `./health-check.sh` ou `health-check.bat`
