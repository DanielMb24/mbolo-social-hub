🎉 AJOUT : Bouton "+" pour créer des conversations

═══════════════════════════════════════════════════════════════

✅ CE QUI A ÉTÉ AJOUTÉ :

1. Bouton "+" dans l'en-tête Messages
   
   • Ouvre un dialog de sélection
   • Liste les personnes que vous suivez
   • Barre de recherche intégrée

2. Dialog de création de conversation
   
   • Affiche vos abonnements (following)
   • Recherche en temps réel
   • Création automatique de conversation

3. Restriction intelligente
   
   • Vous ne pouvez discuter qu'avec les personnes que vous suivez
   • Message clair si liste vide
   • Redirection vers "Personnes"

═══════════════════════════════════════════════════════════════

🎯 COMMENT UTILISER :

1. Allez dans "Messages"
2. Cliquez sur le bouton "+" en haut à droite
3. Sélectionnez une personne dans la liste
4. La conversation est créée automatiquement
5. Commencez à discuter !

═══════════════════════════════════════════════════════════════

⚠️ IMPORTANT :

Vous ne pouvez discuter qu'avec les personnes que vous suivez.

Si vous ne suivez personne :
1. Allez dans "Personnes"
2. Trouvez des utilisateurs
3. Cliquez "Suivre"
4. Retournez dans "Messages"
5. Cliquez sur "+" pour créer une conversation
