========================================
GUIDE D'INTEGRATION - ETAPES SIMPLES
========================================

ETAPE 1: INSTALLER LES DEPENDANCES
========================================

Executer:
  install-chat-deps.bat

Ou manuellement:
  npm install sockjs-client @stomp/stompjs
  npm install --save-dev @types/sockjs-client

========================================
ETAPE 2: CONFIGURER L'EMAIL
========================================

1. Creer le fichier: backend/auth-service/.env

2. Ajouter:
   MAIL_USERNAME=votre-email@gmail.com
   MAIL_PASSWORD=votre-mot-de-passe-application

3. Pour Gmail:
   - Aller sur https://myaccount.google.com/apppasswords
   - Creer un mot de passe application
   - Copier le mot de passe (16 caracteres)

========================================
ETAPE 3: INTEGRER FORGOT PASSWORD
========================================

Dans src/components/mbolo/AuthPage.tsx:

1. Ajouter l'import:
   import { ForgotPasswordDialog } from "./ForgotPasswordDialog";
   import { useState } from "react";

2. Ajouter l'etat:
   const [showForgotPassword, setShowForgotPassword] = useState(false);

3. Ajouter le bouton (dans le formulaire de connexion):
   <button
     type="button"
     onClick={() => setShowForgotPassword(true)}
     className="text-sm text-primary hover:underline"
   >
     Mot de passe oublie ?
   </button>

4. Ajouter le composant (avant la fermeture du return):
   <ForgotPasswordDialog
     open={showForgotPassword}
     onOpenChange={setShowForgotPassword}
   />

========================================
ETAPE 4: INTEGRER LA MESSAGERIE REELLE
========================================

Dans src/components/mbolo/ChatPage.tsx:

1. Ajouter les imports:
   import { chatApi } from "@/lib/chat-api";
   import { wsService } from "@/lib/websocket";
   import { useEffect, useState } from "react";
   import { toast } from "sonner";

2. Remplacer MOCK_CONVERSATIONS par:
   const [conversations, setConversations] = useState([]);
   const [loading, setLoading] = useState(true);

3. Charger les conversations:
   useEffect(() => {
     const load = async () => {
       try {
         const data = await chatApi.getConversations();
         setConversations(data);
       } catch (error) {
         toast.error("Erreur chargement");
       } finally {
         setLoading(false);
       }
     };
     load();
   }, []);

4. Charger les messages:
   useEffect(() => {
     if (!selectedConvo) return;
     const load = async () => {
       const data = await chatApi.getMessages(selectedConvo);
       setMessages(data.content);
     };
     load();
   }, [selectedConvo]);

5. Connecter WebSocket:
   useEffect(() => {
     if (!selectedConvo) return;
     wsService.connect((msg) => {
       setMessages(prev => [...prev, msg]);
     }, selectedConvo);
     return () => wsService.disconnect();
   }, [selectedConvo]);

========================================
ETAPE 5: DEMARRER L'APPLICATION
========================================

1. Demarrer backend:
   cd backend
   docker-compose up -d

2. Attendre 30 secondes

3. Demarrer frontend:
   npm run dev

4. Ouvrir: http://localhost:5173

========================================
PROBLEMES COURANTS
========================================

Email non envoye:
  - Verifier .env existe
  - Verifier mot de passe application Gmail
  - Voir logs: docker logs mbolo-auth-service

WebSocket ne connecte pas:
  - Verifier chat-service demarre
  - Voir logs: docker logs mbolo-chat-service
  - Verifier URL dans websocket.ts

Port deja utilise:
  - Arreter: docker-compose down
  - Redemarrer: docker-compose up -d
