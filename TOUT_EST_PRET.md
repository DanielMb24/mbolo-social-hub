## 🆘 Besoin d'Aide?

### Services ne démarrent pas?
```bash
cd backend
docker-compose down
docker-compose up -d
```

### Erreur 404?
```bash
cd backend
docker-compose restart api-gateway
docker-compose restart user-service
```

### Frontend ne charge pas?
```bash
npm install
npm run dev
```
