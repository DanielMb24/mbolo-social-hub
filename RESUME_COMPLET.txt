╔══════════════════════════════════════════════════════════════════════════════╗
║  🚀 COMMENT UTILISER                                                         ║
╚══════════════════════════════════════════════════════════════════════════════╝

    1. Démarrer le Backend (si pas déjà lancé)
       cd backend
       .\start-backend.bat

    2. Démarrer le Frontend
       npm run dev

    3. Accéder à l'Application
       http://localhost:5174

    4. Tester les Nouvelles Fonctionnalités
       • Partage: Cliquer sur l'icône Share2 sur un post
       • Bookmark: Cliquer sur l'icône Bookmark
       • Menu: Cliquer sur les 3 points (MoreHorizontal)
       • Supprimer: Visible uniquement sur vos posts
       • Signaler: Disponible sur tous les posts
