    🚀 DEMARRAGE RAPIDE :

    1️⃣  GENERER UN JWT SECRET (2 min)
        
        Windows :
        > generate-jwt-secret.bat
        
        Linux/Mac :
        $ chmod +x generate-jwt-secret.sh
        $ ./generate-jwt-secret.sh
        
        → Copiez le secret genere

    2️⃣  OBTENIR LES CREDENTIALS (10 min)
        
        ✓ Gmail App Password
        ✓ Google OAuth (Client ID + Secret)
        ✓ MongoDB Atlas (6 bases)
        ✓ MinIO/S3 (Access Keys)
        
        → Voir GUIDE_VARIABLES_ENVIRONNEMENT.md

    3️⃣  REMPLIR LE FICHIER (5 min)
        
        → Ouvrez .env.render.minimal
        → Remplacez toutes les valeurs
        → Gardez ce fichier en securite


    ═══════════════════════════════════════════════════════════════

    🔑 VARIABLES ESSENTIELLES A CONFIGURER :

    JWT & Securite :
    • JWT_SECRET                    (genere avec le script)

    Email :
    • MAIL_USERNAME                 (votre-email@gmail.com)
    • MAIL_PASSWORD                 (app-password-16-caracteres)

    Google OAuth :
    • GOOGLE_CLIENT_ID              (xxx.apps.googleusercontent.com)
    • GOOGLE_CLIENT_SECRET          (secret-google)

    MongoDB Atlas :
    • MONGODB_AUTH_URI              (mongodb+srv://...)
    • MONGODB_USER_URI              (mongodb+srv://...)
    • MONGODB_CHAT_URI              (mongodb+srv://...)
    • MONGODB_POST_URI              (mongodb+srv://...)
    • MONGODB_VIDEO_URI             (mongodb+srv://...)
    • MONGODB_MODERATION_URI        (mongodb+srv://...)

    MinIO / S3 :
    • MINIO_ENDPOINT                (https://your-minio.com)
    • MINIO_ACCESS_KEY              (access-key)
    • MINIO_SECRET_KEY              (secret-key)


    ═══════════════════════════════════════════════════════════════

    📝 COMMENT IMPORTER DANS RENDER :

    Methode 1 : Via Blueprint (Automatique)
    ────────────────────────────────────────
    1. Allez sur https://dashboard.render.com
    2. Cliquez "New" → "Blueprint"
    3. Selectionnez votre repo GitHub
    4. Render detecte render.yaml
    5. Configurez les variables demandees
    6. Cliquez "Apply"

    Methode 2 : Manuellement (Service par service)
    ───────────────────────────────────────────────
    1. Allez sur le service dans Render
    2. Cliquez "Environment"
    3. Cliquez "Add Environment Variable"
    4. Copiez-collez depuis .env.render.minimal
    5. Sauvegardez

    ⚠️  IMPORTANT - SECURITE :

    ✓ Ne commitez JAMAIS les fichiers .env avec vraies valeurs
    ✓ Ajoutez .env.render* dans .gitignore
    ✓ Utilisez des secrets forts (minimum 256 bits)
    ✓ Activez 2FA sur tous les services
    ✓ Changez les secrets regulierement
    ✓ JWT_SECRET doit etre identique pour gateway et auth
    ✓ MongoDB Atlas : autorisez IP 0.0.0.0/0
    ✓ Gmail : utilisez App Password, pas mot de passe principal
